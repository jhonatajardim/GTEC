## 💻 Como Rodar em Localhost

1. Abra o terminal na pasta do projeto:
   ```bash
   node server.js
   ```
2. Acesse no seu navegador o endereço indicado (por padrão: 👉 **`http://localhost:3000`**).
   *(Caso a porta 3000 esteja ocupada, o script alternará automaticamente para uma porta livre como 8080 ou 5500).*

Se preferir usar Python:
```bash
python -m http.server 3000
```
